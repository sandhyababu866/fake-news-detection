# 🔍 Fake News Detection System

A machine learning-based web application that detects whether a news article is **Real or Fake** using Python, Natural Language Processing (NLP), Scikit-learn, and Flask.

---

## 🌟 Features

* 🤖 Machine Learning-based fake news classification
* 🧠 Natural Language Processing (NLP)
* 🔍 TF-IDF text feature extraction
* 📊 Multiple machine learning models
* 🗳️ Ensemble voting for final prediction
* ⚡ Real-time news prediction
* 📈 Prediction confidence and analysis
* 🌐 Flask-based web interface
* 🛡️ Input validation and error handling

## 🔄 How the System Works

```text
User enters news article
        ↓
Text preprocessing
        ↓
NLP processing
        ↓
TF-IDF feature extraction
        ↓
Machine Learning models
        ↓
Ensemble voting
        ↓
Real / Fake prediction
        ↓
Result displayed on web page
```

---

## 🧠 Machine Learning Models

The system uses multiple classification algorithms.

### 1. Naive Bayes

A probabilistic machine learning algorithm commonly used for text classification.

### 2. Logistic Regression

A classification algorithm used to predict whether the news belongs to the real or fake category.

### 3. Random Forest

An ensemble algorithm that combines multiple decision trees to make predictions.

### 4. Support Vector Machine (SVM)

A machine learning algorithm that finds a suitable decision boundary between different classes.

### Ensemble Prediction

The predictions from multiple models are combined using **majority voting** to determine the final result.

---

## 📝 NLP Processing

The news article is processed before prediction.

```text
Raw News Text
      ↓
Lowercase Conversion
      ↓
Tokenization
      ↓
Stopword Removal
      ↓
Stemming
      ↓
Clean Text
      ↓
TF-IDF Vectorization
```

TF-IDF converts the processed text into numerical features that can be used by machine learning models.

---

## 📊 Dataset

The project uses a labelled dataset containing real and fake news articles.

The dataset is processed and used to train machine learning classification models.

Each news article contains text and a corresponding label indicating whether it is real or fake.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/sandhyababu866/fake-news-detection.git
```

### 2. Open the Project Folder

```bash
cd fake-news-detection
```

### 3. Create a Virtual Environment

For Windows:

```powershell
py -3.12 -m venv .venv
```

### 4. Activate the Virtual Environment

```powershell
.venv\Scripts\activate
```

### 5. Install Required Packages

```powershell
pip install -r requirements.txt
```

### 6. Run the Application

```powershell
python app.py
```

The application will normally run at:

```text
http://127.0.0.1:5000
```

Open the link in your browser.

## 💻 How to Use

1. Start the Flask application.
2. Open the application in your browser.
3. Enter or paste a news article.
4. Click the prediction/detection button.
5. The system processes the news content.
6. The trained machine learning models analyze the text.
7. The system generates the final prediction.
8. The result is displayed as **Real News** or **Fake News**.
